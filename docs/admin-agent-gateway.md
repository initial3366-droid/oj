# 后台业务接口分发给 Agent

Agent 的 `admin_api` 分类通过实际 Spring MVC 路由自动发现后台业务接口，无须在工具中逐一硬编码。接口数量以运行时目录为准；新增后台业务路由在下一次应用启动后进入目录。后台前缀使用 `admin.api-prefix`，不限制为默认路径。

目录和参数契约通过 `list_admin_apis`、`describe_admin_api` 按模块分层发现；`read_admin_api` 调用 GET 查询与导出，`write_admin_api` 调用 POST / PUT / PATCH / DELETE。查询工具绝不能调用写接口。所有通用写入操作（包括新建、导入、发布、批量处理）在原工具执行前进入已有的持久化审批机制，必须选择“是，执行”。选择“否，跳过”或“自定义回复”均不执行原操作。确认绑定当前账号、聊天、助手消息与具体工具调用，刷新可恢复；其他账号、伪造目标和重复确认均被拒绝。原有专用管理工具继续保留修改、删除审批。

## 接口范围

覆盖课程、多班级关联、课程学习报告、定时发布题单、题解树、学生批量管理及原有题库/比赛/人员/站点功能。一级/二级工具目录见 [admin-agent-api-catalog.md](admin-agent-api-catalog.md)。课程专用工具和题单发布工具遵循新版业务约束；题解、批量学生、站点等复用通用网关，避免重复实现 DTO 契约。目录返回模块英文标识及中文说明，支持中文关键词搜索。

以下接口不进入目录，猜测或直接传入路径也不能调用：后台登录与当前管理员账号资料、密码变更、认证与令牌；Agent 自身聊天流、历史、文件传输和审批接口，防止模型自行批准操作或递归调用聊天。旧 XCPCIO 配置/同步接口不再提供给 Agent，仍可通过目录发现有效的 CLICS 导出接口。

配置结果递归移除密码、API key、访问密钥、令牌、认证字段及评测机登录账号。通用工具不接受修改登录凭据和服务密钥；修改完整 OSS/判题配置时由服务端保留隐藏账号字段，口令仍由原设置服务保留。比赛/练习访问密码及新建学生/教师的初始密码属于业务请求，允许按原接口契约创建，不提供修改已有用户登录密码的能力。

## 调用和文件

接口 ID 必须与目录中的 `METHOD 路径模板` 完全一致；分别提供 `path`、`query`、`body`、`files`。不接受任意 URL、请求头、登录令牌或服务器文件路径。调用在进程内通过原 `RequestMappingHandlerAdapter` 进行，保留 Spring MVC 参数转换、默认值、DTO 验证、受保护 Controller 及当前管理员身份，不额外发网络请求或签发登录令牌。

Multipart 文件字段映射到当前聊天的真实上传 `fileId`，再次校验聊天范围及账号所有权。导出结果存为账号私有文件，返回 `/qoj-file/{id}`，聊天界面通过带认证的下载请求获取；删除聊天后清理未被其他聊天引用的导出文件。响应最大 50 MB；JSON 超过 24,000 字符时返回脱敏预览和完整私有 JSON 文件。

## 验证

运行 `node tools/e2e/admin-agent-api.mjs`。脚本使用临时管理员、教师、学生、班级、课程、题单、题目和公告，真实 MVC、SQL 与浏览器，本地脚本模型，不调用外部 AI 或更改真实 AI 凭据。结束清理数据库测试数据及临时后端。

可重复核验产物：`output/admin-agent-api-e2e/report.json`、`catalog.json`（全部接口及参数契约）、课程工具轨迹 `course-tools.json`、确认区域截图和下载样例。失败场景清单见 [admin-agent-gateway-failure-cases.md](admin-agent-gateway-failure-cases.md)。
