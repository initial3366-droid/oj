# 学生列表最后提交时间：实现前失败清单

范围：管理员和教师学生列表新增最后提交时间，按该学生全部个人提交记录取最近的提交时间，不限制 AC、班级、课程或题目；历史记录没有 submit_time 时使用 created_at。没有提交显示“未提交”，日期展示沿用 yyyy-mm-dd。移除两端学号情况筛选，保留学号信息及关键词搜索。

实现前枚举失败方式：
- 取最新插入 ID、判题更新时间或最近 AC，而非最新提交时间；列表只看当前课程或当前班级而遗漏历史提交。
- 多条提交、非 AC 最新记录、乱序插入、跨日期记录、旧数据 submit_time 为空时选错时间。
- 没有提交的学生变成当前日期、空字符串或报错；不同学生的时间串联。
- 每名学生分别查询或前端拉取全部提交列表，导致分页大量重复请求。
- 教师接口新增字段时暴露其他教师学生；调班后丢失学生历史最后提交时间。
- 表格列被挤压，分页或批量选择回归；日期格式与 yyyy-mm-dd 的要求不一致。
- 学号筛选仍残留在任一页面、状态、接口或旧 E2E；误删学号展示或关键词搜索。

通过真实 MySQL/Spring Boot/Redis + Playwright E2E 验证，更新管理员和教师原有 E2E；输出报告、截图和 fixture 清理结果。不新增单元测试。复跑：node tools/e2e/student-management.mjs；node tools/e2e/teacher-student-management.mjs。
