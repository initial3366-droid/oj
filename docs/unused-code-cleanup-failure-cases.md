# 无用代码清理：修改前验证范围

本批不新增单元测试。生产代码修改前建立 HTTP E2E 基线，使用真实应用、临时 MySQL schema 和独立 Redis。

可能失败的情况：

- 删除构造注入参数后，Spring 无法启动或显式构造的测试不再编译。
- ACM/OI 榜单非空时误删参赛者数据，导致昵称、排名、单题状态、成绩变化。
- 把不同赛制的结果混用，或错误调整题目展示顺序。
- 空榜单多查数据库、返回 null 或报错。
- 未指定赛制、显式选择赛制、无效赛制或不存在比赛的响应变化。
- 删除用户查询时误删身份认证所需查询，或以修改权限换取查询数下降。
- 榜单读取产生数据库写入。
- 删除同名方法时误删仍在使用的重载；通过反射访问的私有方法被删除。
- 删除未使用局部变量时一并删除授权校验或资源释放。

验证：新 E2E 比较修改前后 HTTP 状态、完整 JSON、请求线程 SQL 和表数据快照；非空 ACM/OI 榜单必须各少一条用户查询，其他 SQL 一致。检查匿名、学生和管理员调用。运行既有 Maven 测试和 ZIP/连续训练端到端回归；重新扫描 unused 规则。所有结果、日志和独立 diff 保存到 output。
