# 大数据题目性能修复验收

实现前列出的失败路径：
- 仅打开题面编辑页便下载隐藏数据；测试点列表将大文本同时放入 textarea。
- 未修改测试数据，完成操作仍上传、删除、插入全部数据。
- 仅修改一个测试点却重写其他测试点；未展开的数据被空字符串覆盖。
- 保存题面为检查空标准输出，把全部输入/输出读回 JVM；关闭 SPJ 后漏掉空输出校验。
- 增删和编号交换发生唯一键冲突；部分保存失败后留下半成品。
- 新接口越权读取隐藏测试数据；草稿导入和老师 JSON 导入合同改变。
- 大输出比较产生与 token 数成比例的临时字符串；空白比较语义发生改变。

验收使用隔离数据库、真实 HTTP 后端和浏览器 E2E；保留命令、响应字节数、耗时和数据一致性结果。
