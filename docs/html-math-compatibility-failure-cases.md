# 公式兼容性：实施前失败场景

- 含 TeX annotation 的 MathML 被清洗，正文保留而公式空白。
- 复制已渲染 KaTeX HTML 后清洗删除必要布局，公式错位或消失。
- 预渲染的块级公式恢复后变成行内公式。
- 公式源码中的脚本或 HTML 绕过原有清洗规则。
- CODE/PRE 中的公式示例被当作题面公式渲染。
- 普通题目可显示，比赛题目使用相同组件时反而消失。

使用真实浏览器与模拟题面 API，在普通练习和比赛工作区验证原始 LaTeX、带 TeX annotation 的 MathML/KaTeX，保存截图和 JSON 报告。该验证不能证明用户这道题的原始 HTML 属于同一种格式。
