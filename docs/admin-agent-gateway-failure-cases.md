# 管理接口 Agent 分发验证

实施前需覆盖的失败方式：

- 目录漏掉后台业务 Controller、批量操作、题解、文件接口或自定义后台前缀。
- 通过伪造接口 ID、路径、查询参数、请求头绕过登录接口排除规则。
- 查询工具调用写接口，或写工具在确认前执行、拒绝后执行、重复确认重复执行。
- 批量操作、POST 操作、发布、重判、导入及原专用工具绕过确认。
- 请求参数默认值、路径参数、列表、JSON 的原有验证或权限控制失效。
- 附件引用访问其他账号的文件，或读取任意服务器文件。
- 设置查询泄露 API 密钥、判题账号口令、存储密钥；设置修改覆盖凭据。
- 下载结果无法获取、暴露其他账号数据，或过大的结果撑满模型上下文。
- 等待确认时刷新、恢复任务、切换聊天、否决或自定义回复丢失状态。

使用真实 Spring MVC、数据库、浏览器和本地脚本模型完成端到端验证；不调用外部 AI 服务，不新建单元测试。报告及截图写入 `output/admin-agent-api-e2e`。
