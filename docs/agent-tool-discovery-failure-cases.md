实现前失效场景：
1. 首次请求仍有三个发现工具，或系统提示词没有全部分类摘要。
2. 加载分类未将真实业务工具及完整 Schema 加入原有可变回调列表；重复加载产生重复工具。
3. 分类/组不存在、字段缺失、类型错误时未拒绝；加载需要写操作审批或绕过管理员身份检查。
4. 检查点恢复丢失启用范围；旧 categoriesListed/openedCategories 字段导致反序列化失败。
5. 可选组筛选加载了其它组，或后续完整分类加载遗漏剩余工具。
验证边界：先写隔离回归测试再修改实现。使用真实 Workspace、Schema、权限、检查点序列化，依赖 mock；不宣称真实供应商/数据库 E2E。
