# Agent 工具更新的失败场景

实施前核对以下场景，通过真实聊天、脚本模型、MVC、数据库和浏览器验证，产物保存至 `output/admin-agent-api-e2e/`。

- 一级目录缺少课程，或启用课程组后未提供工具；续跑丢失工具组。
- 课程列表无法按关键字分页；详情、题单、报告目标混淆。
- 编辑课程只传标题时，意外清空学期、描述、关联班级或状态。
- 新建/编辑/归档课程未等待确认；拒绝后仍然写入；归档被错误处理为删除。
- 课程无班级却能启用；传入已不存在的班级；操作不存在的课程。
- 发布题单缺少课程、开始时间或截止时间，仍绕过新版后台约束写入。
- 题单发布到课程外班级；截止不晚于开始；题目可见性枚举错误。
- 发布详情和报告无法查询；分页超过 50 条后无法继续读取。
- 工具没有透露题单课程、排序、时间字段，模型无法完成定时发布。
- 学生批量管理或题解工具目录不可发现；API 参数描述与真实 DTO 不符。
- 已撤销的外部评测/同步入口或重复站点维护工具仍出现在工具清单。
- 新功能通过通用接口绕过写入确认，或者暴露认证、密码、密钥和聊天审批。
- 前端只能显示通用进度，课程操作及其确认目标无法辨识。
