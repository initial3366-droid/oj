# 关于页面验证范围

实现前确认以下失败情形；使用真实浏览器完成操作，并将页面中的完整代码交给现有判题容器的编译器运行，保存报告、源码、输入输出及截图。

- 桌面或手机缺少“关于”入口，导航选中状态错误，直接访问或刷新 `/about` 被登录拦截，页面标题未注册。
- 语言遗漏 C、C++17、C++20、C++23、Python、Java 中的任意一项，编译选项、源码文件名或 Java 入口与现有判题配置不符。
- 示例缺少完整入口、不能编译、Java 公开类未命名为 Main、Python 缩进错误或复制内容不完整。
- 将单组输入、首行 T 组输入、读到 EOF 混用；负数、零、超过 32 位的数字、空格和换行混排导致错误，输出多出提示文本。
- 首行 T 的递减循环在 T=0 时仍读取数据或死循环，T=1 时漏算或多算一组，Python 忘记递减导致无限循环。
- 切换语言或输入模式后代码、解释、样例未同步，复制按钮失效或错误提示缺失。
- Accepted 拼写错误，英文状态、系统状态码和中文含义不对应，遗漏现有提交状态，错误地将等待判题解释为判题失败。
- 桌面状态表未位于右侧，手机发生整页横向溢出，长命令无法阅读，beUI 虚拟表格裁切内容。
- 删除前台提交列表的既有行为被新导航改动破坏。

复现：启动 Vite 后运行 `QOJ_E2E_FRONTEND=http://127.0.0.1:5192 node tools/e2e/about-page.mjs`。需本机 Docker 中的 `qoj-go-judge` 容器处于运行状态（可用 `QOJ_E2E_JUDGE_CONTAINER` 指定其他相同判题镜像的容器）。证据保存在 `output/about-page-e2e/`，接口使用确定性浏览器夹具，不修改数据库。
