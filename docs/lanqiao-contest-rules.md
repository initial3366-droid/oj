# 蓝桥杯赛制与成绩发布

依据：蓝桥杯组委会《第十六届蓝桥杯软件赛（C/C++程序设计科目）竞赛规则及说明》，2024-09-29，第七节“答案提交”和第八节“评分”。
高校转载原文：https://sc.liaodongu.edu.cn/static/uploads/res/compattach/202410/20241021092642_4696.pdf

规则说明赛中不显示评测结果，每题最后一次提交作为评测依据，编程题按测试点分值计分。本次采用上述编程赛规则，不新增独立填空答题模块、不限制语言或固定比赛时长。QOJ 保留历史代码以便审计；“提交成功”仅表示系统已接收，不表示答案正确。

## 行为

- 新类型 `LANQIAO` 与 `ACM`、`OI` 并存。管理员和教师使用同一管理页与服务。
- 新建蓝桥杯比赛默认 `scoreboardEnabled=false`、`publicScoreboardEnabled=false`、`resultsPublished=false`。
- 前台榜单与公开外榜分别可配置。蓝桥杯即使开启开关，赛中和赛后未发布时仍不返回成绩；后台授权管理者可检查榜单。
- 比赛结束后，创建者或超级管理员在详情页点击“发布成绩榜单”，或编辑页选择“赛后发布成绩榜单”。发布操作同时打开前台榜单；外榜仍由外榜开关控制。结束时间自动到达不会发布。
- 蓝桥杯所有前台提交接口始终返回 `SUBMITTED` 回执，隐藏实际判题状态、耗时、内存、测试点及通过数量。自己的代码仍可查看。WebSocket 也只发送回执，不发送真实状态。实际提交失败由 HTTP 失败响应反馈。
- 前台通过状态筛选不能探测真实结果，个人已通过题目接口与题目通过数也不泄露结果。
- OI 与蓝桥杯默认整场 100 分，按照题目顺序分配整数余数。例如 3 题为 34、33、33；34 分题的 3 个测试点为 12、11、11。后台直接建题省略分值时也自动分配。支持手动调整每题分值和重新按总分均分；不改写既有比赛分值。
- OI 保持原有最高分计分，蓝桥杯采用比赛时间范围内最后一次提交计分，低分也覆盖此前高分。
- 新 Flyway 迁移 V111 增加榜单开关和发布状态。现有比赛前台榜单保持开启。

## 验证与失效场景

HTTP E2E 在独立临时数据库、空闲 Redis DB15 和临时端口启动真实 Spring 服务；退出时清理临时状态。报告在 `artifacts/lanqiao/http-report.json`。

```sh
python3 tools/verify-lanqiao-contest-http.py
QOJ_LANQIAO_UI=1 python3 tools/verify-lanqiao-contest-http.py
```

第二条还运行构建后的 Vue 页面与真实隔离服务，保存管理员、教师编辑页和学生提交截图及浏览器 trace，不 mock API。运行前执行 `npm run build`。

覆盖默认开关、整数均分、OI 回归、学生提交、AC/WA/CE/TLE/SE 隐藏、状态筛选旁路、通过数泄露、提前发布拒绝、时间结束不自动发布、内榜/rank/快照/外榜访问控制、手动发布、低分最后提交覆盖高分、外榜独立控制、教师创建编辑、管理页保存及学生回执页面。

部署仍需发布后端并让 Flyway 执行 V111、发布新的前端构建；本地隔离验证不代表生产已经更新。

本次验证：32 项端到端检查、6 个真实浏览器流程通过，189 项现有后端测试无失败，前端构建和模板完整性检查通过。详细汇总见 `artifacts/lanqiao/verification.json`。计分状态覆盖采用隔离数据库 fixture；实际提交、访问控制、教师发布按钮及调度器 STOMP 消息通过真实服务验证，未执行完整真实 go-judge 正确答案评测。

## 管理端完整榜单

管理员和创建教师在比赛详情的“排行榜”页签查看完整成绩表，支持刷新。管理专用接口为 `GET /api/admin/v1/contests/{id}/scoreboard`（管理员路径前缀遵循部署配置，教师端复用此接口）。接口校验 `MANAGE_SCOREBOARD` 权限，返回不受封榜、前台开关及成绩发布状态遮蔽的完整榜单，总分降序排列，含所有题目分数和已批准报名但无提交的参赛者。打星选手仍标记打星，但按实际分数所在位置显示。

真实浏览器已在管理员端和教师端分别核对总分 100、70、20、0 的排序及所有单题得分，验证刷新、未提交选手和未发布状态；HTTP 同时验证学生、匿名和非创建教师不可访问管理专用榜单。截图为 `artifacts/lanqiao/admin-complete-scoreboard.png` 和 `artifacts/lanqiao/teacher-complete-scoreboard.png`，汇总见 `artifacts/lanqiao/management-verification.json`。
