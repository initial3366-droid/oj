# 管理员编辑用户验收

实施前列出的失败路径：
- 邮箱未改，但历史学生/管理员记录共用邮箱，修改姓名被误报邮箱重复。
- 改成其他学生或管理员邮箱应被拒绝，失败时姓名、学号和班级不能部分保存。
- 无邮箱的导入学生无法编辑；清空邮箱或学号后数据库仍保留旧值。
- 学号修改不能保存或重复学号未拦截。
- 新建时无法选择已有班级，编辑时班级未回填或切换编辑对象串值。
- 改班只更新 users.class_id，未同步 class_members，造成筛选和课程权限不一致。
- 移出班级未清空关系，或待审批申请将学生重新加入旧班级。
- 不存在/已删除班级导致部分保存；普通资料更新意外移出班级。
- 保持原班级应保留加入时间；重复点击保存不应重复创建账号。

验证命令：node tools/e2e/admin-user-edit.mjs。产物：output/admin-user-edit-e2e/report.json、浏览器截图及 cleanup.json。
