# 题单开放时间与课程变更验证

规则：学生仅在开始时间（含）至截止时间（不含）内查看、解锁和提交题单；教师管理、统计不受开放时间限制。复用比赛的 Arco DatePicker 日期时间组件。旧题单未设置时间时沿用原访问规则，新发布必须设置完整时间。

端到端失败场景：

- 缺少任一时间、截止不晚于开始、时间格式错误应拒绝，已有内容不改变。
- 未开始、已截止的题单不得通过详情、密码解锁、题解或提交 API 绕过限制；学生列表不返回题目内容。
- 已打开的题单和题目页面在截止后清除内容；刷新与重新进入仍拒绝。
- 修改开始与截止时间后立即执行新规则；教师仍能读取和编辑过期题单。
- 编辑可选择同一教师的其他课程，变更后旧班级权限撤销、新课程全部班级获得权限。
- 越权转入其他教师课程、转入草稿或无班级课程、取消课程归属必须拒绝，不能部分更新。
- 变更课程后发布实例 ID、题目与已有提交保持，统计进入目标课程；两个课程相互转移及并发班级修改不能造成权限不同步。
- 发布和编辑表单时间正确回显；同一个组件处理日期与时分，保存后跳转到目标课程。
- 迁移保留旧题单数据；复跑 E2E 清理本次临时数据并输出 JSON 报告和截图。

验证命令：`node tools/e2e/course-refactor.mjs`，产物：`output/course-refactor-e2e/report.json`、页面截图和服务日志。
