# 日期显示统一验证

目标：前台、教师端、管理端的日期展示均为 `yyyy-mm-dd`（例如 `2026-10-06`）。时间选择表单继续保留时分，提交给后端的原始时间和时间窗口判断不变。

浏览器 E2E 验证场景：

- 月、日为个位数时没有补零；部分页面仍显示斜杠、中文日期、时分秒或相对时间。
- 前台比赛详情、提交列表、个人中心、课程题单截止时间与教师/管理端格式不一致。
- 缺失或错误日期显示 `Invalid Date`、`NaN`，导致页面报错。
- 仅含日期的字符串因时区换算发生跨日；带时区的时间未按浏览器本地日期显示。
- 题单编辑误用日期展示函数，导致保存时丢失小时、分钟或截止时间判断变化。
- 表格、详情和悬浮提示使用不同格式；公共 TimeText 继续显示“分钟前”。

验证产物：`output/date-display-e2e/report.json` 与浏览器截图；复跑命令：`node tools/e2e/date-display.mjs`。
