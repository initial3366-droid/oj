# 比赛名单导入与搜索验证

运行：`node tools/e2e/contest-roster.mjs`。报告、截图保存在 `output/contest-roster-e2e/`。

实施前列出的失败场景：

- 未授权学生、非比赛管理者、已删除比赛不得导入或读取报名名单。
- 只能精确匹配学号；用户名、姓名、邮箱即使相同也不得作为后备匹配。
- 学号前导零不得丢失；空输入、超过 5000 条、超过 5MB、损坏文件和缺少学号列必须拒绝。
- 粘贴支持换行、空白、逗号、中文逗号和分号分隔；文件只读取“学号”列，不能误读姓名列。
- 名单内重复学号、已报名学号不能重复新增；不存在、停用或删除的账号应返回明确结果。
- 失败行不能阻止有效行导入；意外数据库错误应回滚整个事务，重试不能重复报名。
- 报名记录和参赛资格必须同步，人数正确；重新导入应保持人数不变。
- 报名搜索覆盖学号、用户名和显示名称，忽略首尾空格及英文字母大小写，清空后恢复全部列表。
- 搜索改变时重置页码；没有结果不应改变总报名人数；导入成功后刷新列表和人数。
- 导入中不能重复提交或关闭弹窗；失败保留输入便于重试；结果可查看每条处理原因。
- 比赛列表入口和详情报名页入口都能使用；文件与粘贴输入不能同时提交。
