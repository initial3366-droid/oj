# Agent 上下文与本地历史验收

编码前明确失败场景：
- 多轮请求遗漏旧消息；超过旧有 40 条 / 60000 字符限制；单条长输入被截断。
- 512K 超预算，输出与工具定义未预留空间；真实模型容量小于512K。
- 摘要失败时覆盖原记录、丢失最新问题；摘要被当成系统授权；工具调用与结果配对被拆开。
- 刷新后历史或摘要丢失；切换账号串历史；IndexedDB容量不足时静默丢记录。
- 流式中断/失败/停止不保存本地结果；旧服务器写入路径仍写入MySQL或Redis。
- 删除、重命名、确认工具操作、继续任务依赖已移除的服务器历史。
- 上下文统计把累计计费当成窗口使用，或把估算冒充精确token。

验收：浏览器E2E拦截API验证多轮请求、刷新恢复、账号隔离、压缩和失败恢复；保留截图与JSON报告。构建及现有后端测试检查兼容性。模型容量为配置值，提供商usage可用时显示实际输入token；本地估算明确标识。
