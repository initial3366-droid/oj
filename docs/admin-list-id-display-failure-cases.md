# 后台列表移除 ID：实现前检查

范围：移除后台表格的数据库 ID 列、名称下附带的数据库 ID，以及嵌套列表中的 ID；学号、教师编号、比赛题目标号、测试点序号和排名保留。

可能失败：遗漏提交记录内嵌用户/题目 ID 或详情中的嵌套列表；名称缺失时又显示 ID；删除 rowKey、接口参数或选择值导致编辑和批量管理失效；固定列或横向滚动宽度不随移除的列调整；修改共用页面时影响教师端。

验证：前端构建和真实浏览器遍历后台列表，使用确定的 API fixture 检查表头及单元格无数据库 ID、行名称仍显示、学生选择和操作仍使用原 ID。保存可复跑脚本、截图和报告。此次仅修改展示，浏览器 fixture 不验证后端权限或数据库行为。
