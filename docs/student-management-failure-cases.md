# 后台学生筛选与批量管理

范围：关键词（用户名、姓名、邮箱、学号）、班级/未分班、任课教师筛选；跨页勾选明确的学生 ID，批量调整班级、移出班级、重置密码、重置 AI 额度、删除。改变筛选条件后清空勾选，最多一次 500 人，提交前展示操作和人数。

实现前枚举失败方式：

- 筛选仅过滤当前页，导致总数、翻页、组合条件错误；重置筛选或切换条件保留旧选择。
- 查询返回过期响应覆盖最新筛选；接口失败仍显示旧数据和勾选；同名班级错误关联。
- 分页时勾选丢失，或批量实际影响所有匹配学生/未勾选学生；重复 ID 重复执行。
- 空列表、超过 500 人、不存在的学生或班级、非学生角色、未知操作、无权限请求未拒绝。
- 批量任一条失败造成部分更新；调班产生两个班级或 users.class_id 与 class_members 不一致。
- 调班后旧课程仍可访问、新课程未自动加入；移出班级错误删除历史提交。
- 班级与“未分班”互斥条件、弱密码或空密码未校验；密码明文出现在日志或响应。
- 删除取消仍提交；错误处理清空勾选导致无法重试；删除失败未整体回滚。
- 并发调班与入班破坏唯一班级约束；批量操作重复点击；页面结果未刷新或 AI 额度显示过期。

使用真实 Spring Boot/MySQL/Redis 与浏览器 E2E，临时夹具在 finally 中清理；不新增单元测试。复跑 `node tools/e2e/student-management.mjs`，产物 `output/student-management-e2e/report.json` 和截图、日志。

使用入口：后台 → 用户管理 → 学生列表。筛选在服务端执行，可组合关键词、班级、教师；“未分班”与班级/教师互斥。创建日期筛选已移除，学号情况筛选已移除，学号仍展示且可搜索。新增最后提交时间，按全部提交记录的最新时间展示；无记录为“未提交”，日期仍统一 yyyy-mm-dd。

勾选支持跨页，每次最多 500 名；更换筛选清空旧选择。批量操作先展示人数与名单，再确认执行。仅系统管理员可操作，后台先验证所有学生并按 ID 加锁，再在一个事务内写入；调班同步班级字段与成员关系，撤销待处理申请并记录管理员，旧审批不能覆盖管理员的移出操作。密码至少 6 个字符且最多 72 字节，使用 BCrypt 独立生成各学生的密码哈希；批量请求等待上限为 5 分钟。AI 重置仅影响所选学生当天额度。删除会清理个人提交等关联记录，确认窗口提示无法恢复。

E2E 覆盖真实数据库权限和非法批量请求、课程访问变更、历史保留及删除级联、并发调班和旧审批冲突，并在浏览器验证跨页选择、失败重试、筛选清空、删除确认和超过默认 15 秒的批量响应。`report.json` 记录每项结果，`cleanup.json` 验证临时学生和班级清理，截图用于核对页面与确认窗口。
