# 用户状态：正常与封禁

实施前验证清单：

- 旧用户和新注册、导入用户默认为正常；状态只有 NORMAL、BANNED，非法值不得写入。
- 只有超级管理员可设置状态；学生和教师无法封禁、解除封禁或修改自己的状态。
- 列表、详情、编辑表单显示真实状态；封禁与解除封禁有明确确认和结果反馈。
- 封禁后正确密码也无法登录，已有 access token 和 refresh token 均不能继续操作。
- 携带封禁账号令牌访问公开接口也必须拒绝，不能降级为匿名继续执行公开操作。
- 提交、比赛报名、聊天、资料修改、AI 等所有账号接口统一拦截，不能仅隐藏前端按钮。
- 已连接 WebSocket 必须断开；新的 CONNECT、SEND、SUBSCRIBE 和消息推送不得绕过封禁。
- 管理员、教师和普通用户的相同数字 ID 不能互相误封禁。
- 封禁用户不能被管理员导入比赛或通过逐个添加获得新的参赛资格。
- 解除封禁恢复正常使用；编辑其他资料不能无意解除封禁；历史报名和提交保留。
- 数据库事务回滚不能提前踢掉用户；测试必须使用可清理的专用账号并输出报告、截图。

重复运行：`node tools/e2e/user-status.mjs`；证据目录：`output/user-status-e2e/`。
