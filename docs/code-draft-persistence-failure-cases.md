# 未提交代码草稿恢复验收（实施前）

- 无提交记录，使用 Python/Java/C++20 写代码后刷新，错误回到 C++17 空编辑器。
- 最近提交语言与草稿不同，异步提交查询覆盖本地草稿语言。
- 模板接口慢于用户输入，初始化/模板恢复覆盖刚输入的代码。
- 多语言切换互相覆盖；刻意清空的草稿被模板替代。
- 不同账号/题目互读草稿；历史草稿没有语言偏好记录无法找回。
- 刷新、离开再进入、服务器重启后同源浏览器草稿应保留。
- 浏览器拒绝 localStorage 写入时，输入不能崩溃，并提示未保存。

端到端验证：node tools/e2e/code-draft-persistence.mjs
产物：output/code-draft-persistence-e2e/report.json、截图。
