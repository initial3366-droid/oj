# 题单编辑加载恢复：失败场景与验证计划

- 新增详情或文件夹选项接口在旧后端不存在，或被数字 ID 路由误匹配并返回通用 500。
- 详情加载失败后自动跳转列表，用户无法重试；错误状态下仍可保存导致覆盖原数据。
- 题单详情降级查询只查前 200 条，遗漏较早题单；权限错误被错误降级。
- 已发布实例仍使用前 500 道题目的下拉框，缺少文件夹范围与服务端分页。
- 跨文件夹添加导致原题目顺序、公开/隐藏状态丢失，或误修改源题单。
- 晚到请求覆盖新查询，页面卸载后继续更新。

验证：真实本地 Spring Boot HTTP 只读检查接口；浏览器用受控 API 覆盖 500/404 兼容、失败停留与重试、已发布实例跨文件夹添加/移除/保存/重新编辑；留存报告、截图、操作轨迹。

当前观察：本地当前源码启动后，`/api/auth_ac/v1/problem-folders/options` 返回 200；数据库中不存在题单 8，因此详情返回明确 404。仅凭线上通用 500，尚不能确定线上堆栈根因；接口版本不一致或旧路由误匹配属于待验证推断。

## 已完成

- 复现并记录了 `HttpRequestMethodNotSupportedException` 被兜底异常处理转换为 500 的情况；现在返回 405，参数类型错误返回 400。新增详情 GET 使用数字 ID 路径约束和显式参数名，避免非数字路径误匹配。
- 题单详情、文件夹选项在接口缺失或通用 500 时尝试旧接口；题单兼容查询遍历分页，不局限前 200 条；401/403 不降级。
- 两种编辑页加载失败均留在原页，显示可重试错误并禁用保存，不自动跳回列表。
- 普通题单和已发布实例共用文件夹分页选题组件。发布实例使用左右布局：左侧候选，右侧已选顺序、移除/清空、公开/隐藏；保存不修改源题单。

## 验证

- 前端构建通过；189 项现有后端测试通过。
- 浏览器 17 项受控 API 场景通过，包含两个新增接口同时返回 500、第二页题单兼容查找、权限错误不降级、编辑失败重试，以及发布实例保存/重新编辑和隐藏状态保留。报告 `.runtime/practice-edit-fix/report.json`，截图 `publication-folder-search.png`，操作轨迹 `trace.zip`。
- 真实可执行后端 JAR 的 5 项本地只读 HTTP 检查通过，包含文件夹轻量选项、题单列表、按 ID 获取详情、错误方法 405、错误参数 400。报告 `.runtime/practice-edit-fix/http-report.json`。
- 本地成功并不能证明线上正在运行同一 JAR。更新应使用修复后的完整部署包，并重启后端；线上仍异常时需要对应请求的服务端堆栈。
