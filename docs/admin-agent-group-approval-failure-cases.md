# 同类操作合并确认的失败场景

实施前检查：

- 同类写操作之间夹着查询或另一类操作，确认面板漏掉后面的同类目标。
- 同一业务通过专用工具和对应通用 API 执行，重复要求确认。
- 创建、修改、删除被误认为同类；通用批量接口中不同 action 被共享授权。
- 确认摘要没有展示全部已计划目标，或模型逐个询问已有信息。
- 同意后续跑丢失授权；拒绝或自定义回复后仍执行同批写操作。
- 工具说明要求逐项询问，模型在系统确认面板之外再要求用户确认。

验证使用真实 Agent 执行循环、Spring AI HTTP 客户端和本地脚本服务；保存可重复运行脚本和 JSON 报告。脚本服务不能验证真实模型遵守提示词的概率。
