# 教师管理功能补齐：验收失败场景

实现前记录；通过真实 HTTP 与浏览器 E2E 验证，不新增单元测试。

- 教师比赛详情的提交、队列按钮跳入 404；直接访问、刷新或返回失效。
- 教师页面错误读取管理员令牌；同时登录两种身份时串用身份。
- 本人比赛非本班学生的提交在队列可见、列表不可见，或无法看详情、代码、导出。
- 其他教师、学生、匿名用户可越权读取或修改比赛提交、队列、答疑、报名。
- 答疑广播只开放页签但仍使用管理员 HTTP / WebSocket 身份，消息不能发送或刷新补看。
- 粘贴或文件导入名单未使用教师身份，重复、未知学号处理不正确。
- 巡查请求未带教师令牌，统计及失败记录与本场比赛不符。
- 教师提交详情缺少分数、测试点、耗时、内存或判题信息；删除、重判、导出缺入口。
- 学生/题目关键词只在当前页过滤；题单提交仅读取前 1000 条，筛选及总数错误。
- 列表和导出采用不同筛选条件；题单页面混入普通练习或比赛提交。
- 管理员原有页面、认证、名单导入、答疑及巡查因共享改造回归。

管理员专属系统设置、Polygon 等权限不在本次补齐范围内。
