摆渡车从秦皇岛校区发车，每到一个校区算“停靠 $1$ 次"：第 $1$ 次停靠在秦皇岛校区（起点），第 $2$ 次停靠在开发区校区，第 $3$ 次停靠在山东堡校区，第 $4$ 次停靠在昌黎校区，第 $5$ 次又回到秦皇岛校区，依此类推。

C · 课表冲突检测

时间限制 1000 ms  |  内存限制 256 MB

在科师每周上课 5 天（周一至周五），每天 8 节课（第 1 节到第 8 节）。每门课占一个连续时段：星期 $d$、第 $l$ 节到第 $r$ 节（含端点）。

新生 $NL$ 拿到了自己的选课清单，共 $n$ 门课。他担心系统出了 bug：如果有两门课在星期几和节次上有重叠（同一星期 $d$，且时段 $[l_1,r_1]$ 与 $[l_2,r_2]$ 有公共节次），那他就得分身去上课了。

请你帮他检测：这份课表是否存在冲突。

输入格式

第一行一个整数 $t$（$1 \le t \le 100$）表示询问组数。

每组询问：

  • 第一行一个整数 $n$（$1 \le n \le 100$）——课程数量；
  • 接下来 $n$ 行，每行三个整数 $d,l,r$（$1 \le d \le 5$，$1 \le l \le r \le 8$）。
输出格式

每组询问输出一行：无冲突输出 YES，存在冲突输出 NO。

样例输入样例输出

3

1 3 4
2 1 8
2

1 3 5

YES
样例解释

第 $1$ 组：两门周一的课分别在 $1–2$ 节和 $3–4$ 节，时段相邻但不重叠；周二全天一门课，无冲突。

第 $2$ 组：两门周一的课在第 $3$ 节重叠，存在冲突。

第 $3$ 组：只有一门课，必然无冲突。

D · 秦皇岛海鲜烧烤

夜幕降临，秦皇岛海边的大排档热闹起来。烤生蚝、烤扇贝、烤鱿鱼、烤大虾……香气随着海风飘散。

烧烤师傅 $Bc$ 有一个特制的双串烤架：一次最多可以同时烤两串海鲜。但是，两串海鲜必须一起烤到其中需要时间较长的那串烤熟为止，较短的那串会提前烤好，但为了等另一串，只能继续放在烤架上（不会烤焦，放心）。

现在有 $n$ 串海鲜，第 $i$ 串需要烤 $t_i$ 分钟。 $Bc$ 可以自由决定哪些串一起烤、以什么顺序烤。如果最后剩下单独一串，就单独烤它，耗时就是它的 $t_i$ 。

输出格式

F · 古诗打卡计划

时间限制 1000 ms  |  内存限制 256 MB

2026 年高考季，一首以白居易《琵琶行》全文为歌词的国风歌曲在抖音爆火，被考生们称为“高考进行曲”。

《琵琶行》全诗 616 言，共 88 句。为了巩固记忆，语文课代表小 $Y$ 制定了一个复习打卡计划：她将需要复习的内容划分为 $n$ 个部分，其中第 $i$ 个部分需要累计复习 $a_i$ 次。为了让复习更有规律，小 $Y$ 制定了两条规则：

  1. 每天最多打卡一次（贪多嚼不烂）；
  2. 同一部分不能连续两天打卡——为了避免机械重复，两次复习同一部分之间至少需要间隔一天。

打卡的日子允许“空转”（某天不进行任何复习）。小 $Y$ 想知道：完成全部复习任务最少需要多少天？

输入格式

第一行一个整数 $t$（$1 \le t \le 10^4$）表示询问组数。

每组询问两行：

  • 第一行一个整数 $n$（$1 \le n \le 2 \times 10^5$）表示需要复习的部分数量；
  • 第二行 $n$ 个整数 $a_1,a_2,\ldots,a_n$（$1 \le a_i \le 10^9$）表示每个部分需要复习的次数。

保证所有询问的 $n$ 之和不超过 $2 \times 10^5$。

输出格式

每组询问输出一行一个整数：完成全部复习打卡的最少天数。

样例输入样例输出

3

样例解释

第 $1$ 组：一种 6 天的安排是 句1 → 句2 → 句1 → 句3 → 句1 → 句2，没有空转，也没有同句相邻。可以证明 6 天是最少的。

第 $2$ 组：句1 要打 4 天，最优安排为 句1 → 句2 → 句1 → 空 → 句1 → 空 → 句1，共 7 天。

第 $3$ 组：只有一句，需要打 7 天，每两次之间都要隔至少一天："打、空、打、空、打、空、打、空、打、空、打、空、打"，共 $2 \times 7 - 1 = 13$ 天。

G · 八十五周年校庆的彩带

时间限制 1000 ms  |  内存限制 256 MB

河北科技师范学院始建于 $1941$ 年，$2026$ 年，学校迎来了八十五周年校庆。

为了筹备 $85$ 周年校庆，筹备组在仓库里收发彩带，准备分发给秦皇岛、昌黎、开发区、山东堡四个校区的同学们系在手腕上作纪念。

彩带按长度存放。为了讨个好彩头，段长必须是正整数（单位：分米），且不能是 $3$ 的倍数——学校形成了涉农、涉教育、涉海洋三大学科群，$“3"$ 要留给学科群，段长一律绕开它。仓库里同一种长度至多保留一段：任意两段的长度互不相同，$85$ 年风雨，每一段岁月都独一无二。

仓库一开始是空的。筹备组会依次进行 $q$ 次操作，每次是下面三种之一：

  1. 1 x：收集一段长度为 $x$ 的彩带。若仓库里已经有这个长度，则不再重复放入；
  2. 2 x：若仓库里有长度为 $x$ 的彩带，就发放这一段；否则什么也不做；
  3. 3：询问当前仓库里有多少种不同的长度。

长度最大可达 $10^9$，请使用 C++ STL 中的 set 维护仓库中现有的长度，并回答每一次询问。

输入格式

第一行一个整数 $q$（$1 \le q \le 10^5$），表示操作次数。

接下来 $q$ 行，每行描述一次操作：

  • 1 x：收集一段长度为 $x$ 的彩带；若该长度已存在，则忽略此次放入；
  • 2 x：若存在长度为 $x$ 的彩带，则发放一段；否则忽略；
  • 3：询问当前不同长度的种数。

保证 $1 \le x \le 10^9$，且 $x$ 不是 $3$ 的倍数。

输出格式

对于每一次询问，输出一行一个整数，表示当前仓库中不同长度的种数。保证至少有一次询问。

H · 迎新夜的许愿牌

时间限制 1000 ms  |  内存限制 256 MB

迎新之夜，数学与信息科技学院的学长们为 $2026$ 级新生准备了一个"扬帆游戏"：广场上摆着 $n$ 块许愿牌，第 $i$ 块牌上写着数字 $i$（$1 \le i \le n$），象征从 1 到 $n$ 的每一段大学时光。

游戏规则是：每回合，玩家任选两块写着数字 $a$、$b$ 的许愿牌（两块不同的牌子，数字可以相同），把它们取下，换上一块写着 $|a-b|$ 的新牌子。游戏进行若干回合后，广场上只剩最后一块许愿牌——它将被挂上进才楼的"心愿墙"，据说数字越大，新学期的好运越多。

作为 XCPC 校队的主力，你被新生们团团围住：最后那块许愿牌上的数字，最大可能是多少？

输入格式

第一行一个整数 $t$（$1 \le t \le 10^4$）表示询问组数。

接下来 $t$ 行，每行一个整数 $n$（$1 \le n \le 10^9$）表示许愿牌的数量。

输出格式

每组询问输出一行一个整数：最后剩余数字的最大可能值。

样例
样例输入样例输出
4
1
2
3
4
1
1
2
4
样例解释

$n=3$：先取 $1$ 和 $2$，$|1-2|=1$，广场剩 $\{1,3\}$；再取 $|3-1|=2$。答案为 $2$。可以证明无法得到 $3$。

$n=4$：先取 $|2-3|=1$，广场剩 $\{1,1,4\}$；再取 $|1-1|=0$，剩 $\{0,4\}$；最后 $|4-0|=4$。答案为 $4$。

I · 欢迎来到邯郸道

时间限制 1000 ms  |  内存限制 256 MB

来邯郸道，逛回车巷、访邯山书院，再到学步桥寻一段成语故事。把古城的风景装进口袋，也把一枚书签夹进书里。

逛完邯郸道，小 $Q$ 想把沿途的记忆做成一面文创书签墙。他准备了 $n$ 张纪念书签，每张印有一个长度为 $L$ 的小写字母串作为纪念码。书签顶端对齐、竖直并排摆放，形成 $L$ 行、$n$ 列；每串的第一个字符在最上方。

小 $Q$ 请来机器人为书签墙生成收藏编号。机器人从左上角开始逐行读取：奇数行从左向右，偶数行从右向左，将字符依次连接成一个字符串，不加入分隔符。

读取前可以任意调整整张书签的左右位置，所有书签各用一次，不得翻转或改变内部字符顺序；读取时不再移动。

小 $Q$ 希望收藏编号的字典序尽可能小，请输出这个编号。比较两个等长字符串时，第一个不同字符较小的字符串字典序更小，字母顺序为 $a,b,\ldots,z$。

输入格式

第一行输入两个整数 $n$ ($1 \le n \le 200$) 和 $L$ ($1 \le L \le 30$)，分别表示书签的数量和每张书签上字符串的长度。

接下来 $n$ 行，第 $i$ 行输入字符串 $s_i$ ($|s_i|=L$)，表示第 $i$ 张书签从上到下的字符。每个字符均为小写英文字母，不同书签上的字符串可以相同。

输出格式

输出一行一个长度为 $nL$ 的字符串，表示机器人能够读出的字典序最小的字符串。不要输出书签编号、摆放顺序、空格或分行后的展示墙。

样例
样例输入样例输出
3 3
aba
aaa
abb
aaaabbaba
1 4
zhao
zhao
3 2
ba
aa
aa
aabaaa
样例解释

样例 1：将第 $1$、$3$、$2$ 张书签依次放在左、中、右，展示墙从上到下的三行分别为 $aaa$、$bba$、$aba$。机器人第一行从左向右读出 $aaa$，第二行从右向左读出 $abb$，第三行从左向右读出 $aba$，连起来是 $aaaabbaba$。这就是本例能够得到的字典序最小的字符串。

样例 2：只有一张书签，无论每一行的读取方向如何，每行都只读一个字符，最终得到 $zhao$。

样例 3：将两张写着 $aa$ 的书签放在左边和中间，写着 $ba$ 的书签放在右边，得到展示墙的两行 $aab$、$aaa$，读出的字符串为 $aabaaa$。两张内容相同的书签都必须使用。
